# Product Requirements — Personal AI Job Application Agent

## Objective
Reduce repetitive job-search work while improving application relevance and maintaining user control over irreversible submissions.

## Primary users
Single primary user: Tarun Singh Gohil.

## Core capabilities
- Maintain career profile and preferences.
- Discover new jobs from configured sources.
- Normalize and deduplicate listings.
- Apply hard filters.
- Score and explain job fit.
- Recommend an appropriate resume variant.
- Tailor application materials without fabricating experience.
- Maintain reusable application answers.
- Put restricted/manual sources into an approval queue.
- Track applications and follow-ups.
- Notify the user.
- Learn from outcomes while preserving explicit user rules.

## UX principles
- Dashboard-first.
- Every recommendation should explain why.
- User can edit rules without code.
- Secrets are configured in Settings, not pasted into prompts.
- Job actions are reversible until submission.

## Success metrics
- Relevant jobs discovered per day.
- High-quality match rate.
- Application preparation time saved.
- Interview rate by job source/role/resume variant.
- False-positive rate.
- Duplicate rate.
