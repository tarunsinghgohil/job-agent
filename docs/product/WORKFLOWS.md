# Product Workflows

## Daily discovery
Scheduler -> sources -> parse -> normalize -> dedupe -> qualify -> score -> rank -> notify.

## Application preparation
Selected job -> choose resume -> tailor -> generate cover letter if useful -> populate answer bank -> validation -> approval queue.

## Allowed auto-submit
Only where source integration explicitly permits programmatic submission and the configured adapter supports it.

## Restricted/manual source
Prepare application package -> show checklist -> user approves/completes external submission -> user marks submitted -> tracker updates.

## Follow-up
Scheduled check -> find stale/pending applications -> notify according to user settings.

## Learning
Outcome data -> aggregate by role/source/resume -> report patterns -> propose rule/model changes -> user approves changes.
