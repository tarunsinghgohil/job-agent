# Resume Strategy

## Master resume
The repository contains the user's supplied 2026 frontend resume as initial source material.

## Target variants
1. `react-frontend` — default for React/frontend roles.
2. `frontend-lead` — for lead/architecture ownership roles.
3. `ai-frontend` — for AI + frontend roles.
4. Additional variants may be added by the user.

## Selection rules
- Prefer the variant with strongest evidence for the target role.
- Preserve factual experience and dates.
- Tailor ordering/wording, not underlying truth.
- Never invent a technology, title, employer, certification, metric, or project.
- Surface the selected variant and reasons in the dashboard.

## User experience
Dashboard must support upload, rename, activate/deactivate, preview, versioning, and job-specific recommendation.
