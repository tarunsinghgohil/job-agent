# Resume Evidence Rules

1. Every tailored claim must trace to an approved resume/profile source.
2. Do not invent numeric metrics.
3. Do not upgrade "exposure" into "expert" without evidence.
4. Preserve employer/title/date chronology.
5. A missing keyword may be omitted, not fabricated.
6. Prefer evidence snippets when producing a job-match explanation.
7. User can approve a new skill/claim only by editing the profile or resume source.
